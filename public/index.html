N°07 — Run it
  1. npm install && npm start in the youtube-downloader folder.
  2. Open http://localhost:3123, paste a link, hit Fetch.
  3. Pick a row. The server streams it via yt-dlp — nothing is stored.

Requires yt-dlp and ffmpeg on PATH. Personal / fair-use downloads only — respect creators.
